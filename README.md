## Карманный переводчик & Pocket Translator

### Навыки бота:

- Бот умеет переводить на три доступных ему языка:
	- Русский 
	- Английский
	- Французский
------------------------------------------------------
## Использование бота в Telegram:

#### 1. Ввести команду 
`/start` -- бот поздоровается и расскажет о 	себе
#### 2. Нажать на кнопку или ввести команду
`💬 Перевести 💬` или `/translation`

#### 3. Написать текст для перевода
###### Пример:
`/translation (ваш текст для перевода)`

#### 4. Выбрать язык на котором написан ваш текст

#### 5. Выбрать язык на который хотите перевести

#### Примечание:
- Если вы выберете язык, на котором написан текст, то бот его не переведёт

- Если вы введёте язык, которого нет, то бот использует предыдущий язык

## Установка & Настройка & Запуск

#### 1. Установка
- Установить [.NET](https://github.com/pandao/editor.md "Heading link") на свой тип ОС
- Скопировать репозиторий командой `git clone https://github.com/a1exx2a/Bot.git`

#### 2. Настройка
- Создайте Telegram бота в главном боте [@BotFather](https://t.me/BotFather) и получите API токен

- По умолчанию бот работает с Google Transalate API, но так же может работать с Yandex Translate API, для него тоже нужен API токен, подробнее можно узнать [ТУТ](https://yandex.cloud/ru/docs/translate/operations/sa-api-key)

- Все полученные токены скопируйте в файл config.cs и не кому не показывайте

#### 3. Запуск
- Запустите бота командой `dotnet run` в консоле вы увидете сообщение о том, что бот запущен и информация о нём.
